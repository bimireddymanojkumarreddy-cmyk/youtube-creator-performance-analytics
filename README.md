# YouTube Creator Performance Analytics

## Project Overview
An analytics project focused on exploring YouTube creator performance using SQL and Power BI. The project aims to help analyze channel performance, video engagement, and key performance indicators through data analysis and interactive visualizations.

## Tools & Technologies
- **Power BI** — Dashboard development and data visualization
- **SQL** — Data querying and analysis

## Project Files
- `youtube analytics dashboard project.pbix` — Power BI dashboard
- `youtube creator performance analytics.sql` — SQL analysis queries

## Key Objectives
- Analyze YouTube creator and video performance.
- Explore engagement and performance metrics.
- Use SQL to extract insights from the dataset.
- Present findings through an interactive Power BI dashboard.
